## Overview

Most layouts start from a tool: you pick the terminal or the file manager, then a host. Host Layout starts from the host. Your folders, hosts and sub hosts sit in a tree on the left, with the containers and VMs that run on them underneath. Pick a host and every tool it has shows as a tab on it: Overview, Terminal, Files, Docker, Metrics and the rest.

Sessions keep running when you move to another host, and coming back shows the tab you left. You can switch layouts in Settings, Appearance.

Read the [docs](https://docs.termix.site/plugins/host-layout) to learn how it works.

<br />

## Features

- Tree of folders, hosts and sub hosts with search, status dots and badges
- Containers and VMs from Docker, Proxmox and Virtual Machines listed under their host
- Every tool and session for a host as a tab on it, with an Overview tab first
- Sessions keep running when you switch hosts, and each host remembers its last tab
- Open pages like Settings or plugin pages listed under the tree
- Tools menu for everything that doesn't need a host, with plugin panels on the right
- Dashboard, Manage, Settings and the host editor from Classic Layout
- Phone view with the tree first and a back button
